L・R・T方向のヤング率と、同じ応力・同じひずみ・同じ力という比較条件を整理します。断面形状のI・Z、文字式による高さの比較、教科書の「4倍の力」とたわみ、節・目切れ、試料差、授業での説明を扱います。

35枚、Nanami（速度 −5%・既定ピッチ）、字幕558件。休憩は25:20、48:55、75:52から各約68秒です。説明の後に計算・作図・記述の時間と解説があります。必要に応じて一時停止してください。MP4には選択式の日本語字幕と章区切りを収録しています。
