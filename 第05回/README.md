フックの法則を復習し、kg・kgf・N・Paをつなぎ、原典の物性表からヤング率と曲げ強さを読み取ります。中央集中荷重のつりあい、I・Z、たわみと応力の計算、長さ・高さの比較、学校での測定計画へ進みます。

35枚、Nanami（速度 −5%・既定ピッチ）、字幕609件。休憩は25:47、50:00、73:34から各約82秒です。説明の後に計算・作図・記述の時間と解説があります。必要に応じて一時停止してください。MP4には選択式の日本語字幕と章区切りを収録しています。

木材の物性値は、樹種・方向・含水率・試験条件と一緒に読み取ります。小さな無欠点試験片の代表値を、手元の部材の保証値や設計用の許容値として用いません。仮想データは説明用と明記しています。出典・条件・リンクは資料とスライドのノートに記載しています。

## 音声が流れない区間について

演習で考えたり、計算・作図・記述したりする時間には、音声が流れません。その間は画面上部に「考える時間（音声なし）」「残り時間」「再開時刻」を表示します。休憩では「休憩中（音声なし）」と表示します。カウントダウンが進んでいれば動画は再生中で、表示が終わると音声が再開します。この表示は字幕をオフにしても消えません。必要な場合は再生を一時停止して取り組んでください。
