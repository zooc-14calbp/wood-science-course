# 第2回　組織と年輪

## オンデマンド（90分）

- Dropbox：このフォルダーの `02_オンデマンド_授業動画.mp4` を開いてください。
- GitHub：[動画・MP3音声・字幕](https://github.com/zooc-14calbp/wood-science-course/releases/tag/lecture02-20261024)
- [授業スライド PDF](02_オンデマンド_授業スライド.pdf) ／ [PPTX](02_オンデマンド_授業スライド.pptx)
- [配布資料 PDF](02_オンデマンド_配布資料.pdf) ／ [テキスト](02_オンデマンド_配布資料.md)
- [字幕 SRT](02_オンデマンド_授業動画.srt) ／ [VTT](02_オンデマンド_授業動画.vtt)

音声はNanami、速度 -5%。休憩3回と考える時間を含め90分です。日本語字幕は再生ソフトで選択してください。写真や計算を確かめるときは一時停止できます。

前半は、細胞の種類・壁と内腔・軸方向と放射方向の系を観察します。年輪の内部を見た後に、壁の割合から密度を計算し、早晩材率と年輪全体の密度、方向による性質の違い、加工、技術科での説明へ進みます。

18枚目の写真は実際の組織、重ねた密度曲線は説明用のモデルです。写真から密度を実測したものではありません。計算の設定値と実材の測定値を区別してください。

演習と復習の問いは自己確認用です。既存の提出課題A1～A4の提出方法・締切は授業の指示に従ってください。
