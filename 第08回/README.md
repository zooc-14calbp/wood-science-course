含水率はまず水の質量を取り出し、何を基準に割るかを考えます。

木材：MC_w（%）＝［（全乾木材＋水）−全乾木材］／全乾木材 ×100。

食品・農産物：MC_f（%）＝［（乾物＋水）−乾物］／（乾物＋水）×100。

w＝wood、f＝foodは本講義での区別用です。乾量基準はdb、湿量基準はwbとも書きます。分数での水分比と百分率の含水率を区別します。木材・食品とも分野や用途により他方の基準を使う場合があります。

同じ「水20 g・乾物100 g」でも、乾量基準20%、湿量基準約16.7%です。乾量基準は乾いた材料に対する水の量、湿量基準は水を含む全体に占める水の割合を表します。木材の乾量基準は100%を超え得ます。意味・相互換算・測定・水の場所・強度との関連を扱います。
