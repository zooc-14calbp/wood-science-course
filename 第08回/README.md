更新日：2026年10月27日

木材の含水率は `(M−M₀)/M₀×100`、食品等でよく用いる湿量基準は `(M−M₀)/M×100`。水の質量を取り出す分子は、いずれも「（全乾木材＋水）−全乾木材」です。
