## 1　C・H・Oと化学式：高校化学の復習

木材の主要な有機成分を読むために、炭素C、水素H、酸素Oを確認します。中性の典型的な有機分子では、Cは4本、Hは1本、Oは2本分の共有結合をつくることが、構造を読む基本になります。二重結合は2本分として数えます。イオン等には別の扱いがあるため、全ての状態に機械的に当てはめる規則ではありません。

| 例 | 式から分かること | 式だけでは決まらないこと |
| --- | --- | --- |
| H₂O | Hが2個、Oが1個 | 結合角や、水同士の配置 |
| C₆H₁₂O₆ | Cが6個、Hが12個、Oが6個 | 原子のつながりや立体配置 |
| C₂H₆O | Cが2個、Hが6個、Oが1個 | エタノールかジメチルエーテルか |

下付きの数字は、直前の元素の原子数を示します。H₂Oの2はHだけに付きます。係数2H₂Oなら、水分子が2個分なので、合計Hは4個、Oは2個です。原子を数える際は、下付きと係数を区別します。

OH基は、分子の一部にある−O−Hです。OH基があることは、水H₂Oが一分子として含まれていることと同じではありません。また、OH基と水酸化物イオンOH⁻も、電荷や結び付きが異なります。

C₆H₁₂O₆をC₆(H₂O)₆のように整理して書けても、糖の中に6個の水分子がそのまま入っているという意味ではありません。「炭水化物」という名称から、水分量を計算しないことが大切です。

参照：25章導入 carbohydrateの名称と構造 https://openstax.org/books/organic-chemistry/pages/25-why-this-chapter

## 2　結合と構造式の読み方

共有結合は、原子が電子対を共有してつながる結合です。構造式の実線一本は単結合、二本は二重結合を表します。長い分子の鎖をつくる共有結合と、鎖同士の水素結合を、同じ意味の線として読みません。

| 表し方 | 例 | 読み方 |
| --- | --- | --- |
| 分子式 | C₂H₆O | 種類ごとの原子数を示す |
| 縮合構造式 | CH₃−CH₂−OH | 炭素のつながりとOHの位置を示す |
| 別の構造 | CH₃−O−CH₃ | 同じC₂H₆Oでも、酸素を挟むつながり |
| 骨格式 | 折れ線の角と端 | Cを省略し、Cに付くHも通常は省略する |

骨格式では、特に元素記号がない角と端が炭素を表します。Oなど別の元素を記した場所を、炭素として二重に数えません。炭素に付くHは、典型的な価数4を満たす数として補います。

CH₃−CH₂−OHのHを数えると3 + 2 + 1 = 6です。CH₃−O−CH₃では3 + 3 = 6。どちらもC₂H₆Oですが、前者はエタノール、後者はジメチルエーテルです。同じ分子式でも、つながりが違えば性質が変わります。

OHとHOは、結合先を分かりやすくするために書く向きを変えた表記です。左側の鎖へ酸素でつながる部分をHO−と書く場合があります。文字の並びだけで別の官能基と判断せず、どの原子が結合しているかをたどります。

参照：1.12 Drawing Chemical Structures https://openstax.org/books/organic-chemistry/pages/1-12-drawing-chemical-structures

## 3　木材の構造式で探す官能基

官能基は、分子内の特徴的な原子のまとまりです。官能基を探すと、水との相互作用や反応を考える入口が得られます。ただし、性質は官能基の名前だけでなく、周囲の構造や集合状態にも左右されます。

| 名称・部分 | 一般的な表し方 | 木材で読む手掛かり |
| --- | --- | --- |
| ヒドロキシ基（OH基） | R−OH | 糖やリグニンにも存在。水との水素結合に関わる |
| フェノール性OH | 芳香族環−OH | 芳香族環に直接つながるOH。アルコールのOHと環境が違う |
| エーテル結合 | R−O−R′ | 酸素を挟んで有機基がつながる。糖の環や高分子の結合を読む |
| カルボニル基 | C=O | アルデヒド・ケトン・エステル等に含まれる |
| カルボキシ基 | −C(=O)OH | 糖の酸化体等を読む。条件により−COO⁻となる |
| エステル結合 | R−C(=O)−O−R′ | キシラン等のアセチル化された部分にも関わる |
| メトキシ基 | −O−CH₃ | リグニン等で見られる。−OHとは異なる部分 |

この表のRやR′は、分子の残りの部分をまとめた記号です。木材の放射方向Rとは意味が異なります。プライム′は、二つの残りの部分を区別する印です。

アセチル基−C(=O)CH₃と、メトキシ基−OCH₃を混同しません。ヘミセルロースの構造式では、主鎖の糖だけでなく、その横に付く部分も確認します。

参照：3.1 Functional Groups https://openstax.org/books/organic-chemistry/pages/3-1-functional-groups

## 4　立体構造式と立体モデル

分子の原子は三次元に配置しています。飽和炭素の4本の結合は、典型的には正四面体に近い方向へ向きます。全ての炭素がこの形というわけではなく、芳香族の環の炭素等は別の結合環境をもちます。

| 図の記号 | 表すこと | 混同しやすいこと |
| --- | --- | --- |
| 通常の実線 | 紙面にほぼ沿う結合 | 分子間の水素結合ではない |
| 太いくさび | 手前へ出る結合 | 原子や分子が太いことを示すのではない |
| 細かい破線のくさび | 奥へ向かう共有結合 | 水素結合を表すH···Oの点線とは意味が違う |
| いす形の糖環 | 環が平面ではないこと | 六員環の6頂点が全て炭素とは限らない |

グルコースのピラノース環は、5個の炭素と1個の酸素を含む六員環です。残る炭素は環外のCH₂OHの部分にあります。炭素6個という分子全体の数と、環の頂点の数を区別します。

αとβは、環になった糖のアノマー炭素（グルコースではC1）の配置の違いを表します。通常のD-グルコピラノースの図では、C1に付くOHとC5側のCH₂OHが同じ側ならβ、反対側ならαです。紙面で常に「上ならβ」と覚えず、二つの基の相対的な向きを読みます。

分子の向きを紙の上で回しても、αとβが入れ替わるわけではありません。単結合まわりの回転で変わる配座と、結合を保ったまま単純には入れ替わらない立体配置の区別は発展事項です。モデル図は、状態や計算条件を伴う形の一例として使います。

参照：1.4 四面体とくさび表記 https://openstax.org/books/organic-chemistry/pages/1-4-development-of-chemical-bonding-theory

参照：25.5 糖の環とアノマー https://openstax.org/books/organic-chemistry/pages/25-5-cyclic-structures-of-monosaccharides-anomers

## 5　極性・水素結合・水への親和性

酸素と水素は、結合の電子を同じ強さでは引き付けません。O−H結合では電子の分布が酸素側へ偏り、酸素側と水素側に部分的な電荷の偏りが生じます。これは、常にOH⁻とH⁺へ分かれているという意味ではありません。

水素結合は、適切な相手と配置の間で生じる相互作用です。講義の例は、壁の−O−HのHと、水分子のOの間のH···Oです。壁のO−Hや水の二本のO−Hは分子内の共有結合で、実線を残します。水同士や成分同士の間にも水素結合が生じます。

| 用語 | ここで区別すること |
| --- | --- |
| 親水性 | 水と相互作用し、なじみやすい。水に溶けることと同じではない |
| 疎水性 | 水との親和性が比較的小さい。「完全防水」「吸湿ゼロ」と同じではない |
| 分子の性質 | OH基等の存在と、水がその場所へ近付けるかを合わせて考える |
| 表面と内部 | 水滴のぬれ方を見ただけで、材料全体の吸湿を決めない |

セルロースにはOH基がありますが、鎖の集合内部は水が入りにくい領域を含みます。表面等では水が関わり、壁は吸湿・膨潤します。「水に簡単に溶けないから、水と関係しない」という説明にはしません。

吸湿は水蒸気とのやり取り、吸水は液体の水との接触を含む過程として、観察条件を添えて扱います。実際の木材では、通り道、表面処理、方向、時間、温湿度も確認します。

参照：IUPAC hydrogen bond https://goldbook.iupac.org/terms/view/H02899

参照：IUPAC hydrophilic / hydrophobicity https://goldbook.iupac.org/terms/view/H02906 ／ https://goldbook.iupac.org/terms/view/HT06964

参照：水と細胞壁 Water in Wood (2022) https://doi.org/10.3390/f13122051

## 6　糖質の分類：単糖・二糖・多糖

単糖は、加水分解してさらに小さな糖へ分けることのできない糖です。複数の単糖由来の単位がグリコシド結合でつながると、二糖や多糖になります。「糖質」は全てが甘く水に溶けやすい、という意味ではありません。

| 分類 | 例 | 木材との関係 |
| --- | --- | --- |
| 単糖：六炭糖 | グルコース、マンノース、ガラクトース | 炭素6個。糖の種類や配置は同じではない |
| 単糖：五炭糖 | キシロース、アラビノース | 炭素5個。キシラン等の構成に関わる |
| 二糖 | セロビオース、マルトース | ともにグルコース由来だが、主な結合のα／βが異なる |
| 多糖 | セルロース、キシラン、グルコマンナン、デンプン | 単位の種類、結合、側鎖、集合状態の違いを見る |

グルコースとマンノースは分子式がともにC₆H₁₂O₆でも、特定の炭素でOHの配置が違います。グルコースとキシロースでは、炭素数も異なります。「全てが小さな六角形」という略図だけでは、この違いは分かりません。

セルロースはグルコース由来の単位をもつ多糖です。ヘミセルロースは複数種の多糖の総称で、構成糖や側鎖が異なります。リグニンはこの分類の多糖ではなく、芳香族構造を含む別の種類の高分子です。

参照：25章まとめ 糖の構造と分類 https://openstax.org/books/organic-chemistry/pages/25-summary

## 7　グリコシド結合と、セルロース・デンプンの違い

グリコシド結合を読むときは、①どの糖の単位か、②αかβか、③何番と何番の炭素に関係する結合か、を確かめます。β(1→4)は、ある糖単位のC1と次の糖単位のC4が関わる結合を表します。

| 多糖 | 主な結び方 | 区別したいこと |
| --- | --- | --- |
| セルロース | β(1→4)グルコース鎖 | 単位はグルコース。鎖の伸びた形と集合が壁を支える |
| アミロース | α(1→4)グルコース鎖 | デンプンの一成分。結び方により空間的な形が違う |
| アミロペクチン | α(1→4)の主鎖とα(1→6)の分岐 | デンプンの分岐をもつ一成分。全デンプンを一本鎖や全て分岐と一括しない |

糖が二つつながり水一分子が差し引かれる関係を、原子数の収支として書くと、2 C₆H₁₂O₆ → C₁₂H₂₂O₁₁ + H₂Oとなります。逆向きは水を使って結合を切る加水分解です。この収支式だけで、細胞内の実際の合成反応の仕組みを全て表したことにはなりません。

セルロースの繰り返し単位は(C₆H₁₀O₅)ₙと表されます。末端の細部を省略した高分子の表記として読みます。遊離したグルコースC₆H₁₂O₆が、そのまま何も変わらず並んだ式ではありません。

通常の吸湿で壁に水が関わることと、グリコシド結合が加水分解されて糖へ分かれることは別です。加水分解の進み方には、酸や酵素等の条件も関係します。水素結合の組み替わりを、主鎖の共有結合が全て切れたことと混同しません。

参照：25.9 Polysaccharides and Their Synthesis https://openstax.org/books/organic-chemistry/pages/25-9-polysaccharides-and-their-synthesis

## 11　分子から細胞壁へ：木材と水、含水率への接続

成分の構造式を読めても、木材全体の吸湿量や強度が一つに決まるわけではありません。成分の量、集合と配向、細胞の配列、欠点、水の通り道、温湿度や時間を合わせます。内腔等の水と、細胞壁内で成分と相互作用する水も区別します。

第4回では含水率を軽く紹介し、第8回で二つの基準を比較します。Mは水を含む試料の質量、M₀は乾いた材料の質量です。分子を言葉で書き直し、何が差し引かれて水だけが残るかを確かめます。

M − M₀ =（全乾木材 + 水）− 全乾木材 = 水の質量

MC_w（%）=［（全乾木材 + 水）− 全乾木材］/［全乾木材］×100

木材で通常使う乾量基準は、乾いた材料に対して水がどれだけあるかを表します。食品・農産物でよく使う湿量基準は、水を含む全体に占める水の割合です。食品では「全乾木材」を「乾物」に置き換えます。

MC_f（%）=［（乾物 + 水）− 乾物］/［乾物 + 水］×100

同一試料で乾物50 g、水75 gなら、分子はどちらも(50 + 75) − 50 = 75 g。乾量基準は150%、湿量基準は60%。水の量を変えたのではなく、比較の基準が違います。比で表すときは×100を付けません。食品でも乾量基準を使う場合があるため、資料のdb／wbを確認します。

参照：Wood Handbook第4章・FAO 乾量／湿量基準 https://research.fs.usda.gov/treesearch/62243 ／ https://www.fao.org/4/t1838e/T1838E0u.htm

## 自己確認の解説

| 問 | 解答の要点 |
| --- | --- |
| 1 | ともにC₂H₆O。Hは前者3+2+1、後者3+3。前者はOHをもつエタノール、後者はOを挟むジメチルエーテル。つながりが異なる。 |
| 2 | OH基は分子の一部、H₂Oは酸素1・水素2の水分子、OH⁻は負電荷をもつイオン。組成と電荷・結び付きが異なる。 |
| 3 | 壁−O−H···O（水）のH···Oを点線にする。水のOにはHが二つ、実線でつながる。水のH···壁のOという適切な例も可。 |

| 6 | ヘミセルロースはキシラン類・グルコマンナン類等の総称。リグニンは芳香族の構成を含む高分子で、多糖ではない。 |
| 7 | OH基はあるが、集合内部への水のアクセスは限られる。表面等や周囲の成分へ水が関わることと、鎖全体が溶けることを区別する。 |
| 8 | 水=(100+20)−100=20 g。乾量：20/100×100=20%。湿量：20/120×100=16.666…%（約16.7%）。 |
