# 第4回　主要構成成分

## オンデマンド（90分・タイトル付き）

- Dropbox：このフォルダーの `04_オンデマンド_授業動画.mp4` を開いてください。
- GitHub：[動画・MP3・字幕](https://github.com/zooc-14calbp/wood-science-course/releases/tag/lecture04-20261024)
- [授業スライド PDF](04_オンデマンド_授業スライド.pdf) ／ [PPTX](04_オンデマンド_授業スライド.pptx)
- [配布資料 PDF](04_オンデマンド_配布資料.pdf) ／ [テキスト](04_オンデマンド_配布資料.md)
- [字幕 SRT](04_オンデマンド_授業動画.srt) ／ [VTT](04_オンデマンド_授業動画.vtt)

セルロース・ヘミセルロース・リグニンを、前回の細胞壁の図へ対応させます。OH基と水分子、水素結合、親水性・疎水性、水のアクセスから、吸湿・膨潤を考えます。親水性と水溶性、表面のぬれ方と内部の吸湿を区別します。

冒頭に科目情報のタイトルページがあります。35枚、Nanami（速度 −5%）、字幕776件。休憩は25:28、50:52、72:30から各約47秒です。演習は成分の質量割合、比喩の対応と限界、水との関係の図解の3段階。必要に応じて一時停止してください。MP4には選択式の日本語字幕と章区切りがあります。
