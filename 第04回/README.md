## 最初に開くもの

1. **動画**：[GitHubで開く](https://github.com/zooc-14calbp/wood-science-course/releases/tag/lecture04-20261027-wait)。Dropboxでは `04_オンデマンド_授業動画.mp4` を開きます。

自己確認は解説と照合します。提出課題は第4回後の **A1** です。[課題一覧](../README.md#提出課題)で設問と回答フォームを確認してください。正式な配信元・提出先はTeamsです。締切・提出形式はTeamsの案内に従います。
