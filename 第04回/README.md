細胞壁と三成分、OH基・水素結合、親水性・疎水性、水のアクセスから吸湿・膨潤へ進みます。構造式と立体モデルには出典と説明を付けています。ヘミセルロースとリグニンは、代表的な部分・結合モデルであることを区別します。

質量百分率は一般名称として説明します。今回は全乾木材全体を分母とする成分割合を計算します。含水率は第8回への短い導入です。水の質量を「（全乾木材＋水）−全乾木材」と明示し、木材の含水率では全乾木材を分母とします。食品・農産物の湿量基準との比較は[第8回](../第08回/README.md)で扱います。

38枚、Nanami（速度 −5%・既定ピッチ）、字幕764件。休憩は25:31、47:05、72:08から各約69秒です。演習は成分の質量割合、比喩の対応と限界、水との関係の図解の3段階。必要に応じて一時停止してください。MP4には選択式の日本語字幕と章区切りがあります。

## 音声が流れない区間について

演習で考えたり、計算・作図・記述したりする時間には、音声が流れません。その間は画面上部に「考える時間（音声なし）」「残り時間」「再開時刻」を表示します。休憩では「休憩中（音声なし）」と表示します。カウントダウンが進んでいれば動画は再生中で、表示が終わると音声が再開します。この表示は字幕をオフにしても消えません。必要な場合は再生を一時停止して取り組んでください。
