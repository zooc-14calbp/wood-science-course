# 第13回の仮想データ

以下は本講義で作成した計算・説明用のデータです。実験結果、製品の保証値、構造設計用の値ではありません。

- [EIの比較（CSV）](仮想データ_EI比較.csv)：スライド16の棒グラフはEIを10⁶ N·mm²単位で表示します。A=225、B=194.4。中央集中荷重、単純支持、小変形、同じ方向のEを一定とする曲げのモデルです。
- [荷重とたわみ（CSV）](仮想データ_荷重とたわみ.csv)：スライド67の記録表と68のグラフ。予測はA案のδ=FL³/(48EI)。比較する「測定値役」も作成した仮想値であり、実測ではありません。

試験体の幅・高さ、支持間隔と部材全長、方向、含水状態、荷重位置、測定位置を確認します。実物では、接合の変形・せん断変形・ばらつき等が影響します。合った式を使い、式の適用範囲を確かめます。
