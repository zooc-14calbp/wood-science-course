# 第13回 ICTを活用した木材加工の考察

授業内の考察・提案用です。正式な提出課題の指定・期限はTeamsで確認してください。

## 検討段階として扱うこと

「情報・技術科（仮称）」の内容と、中学校現場での具体的な実施方法は、なお検討されている段階です。学校ごとの設備、授業時数、担当者の経験、予算、準備・片付け、保守等の条件もあり、全国の学校が同じ方法へ移行すると決まったものとして扱いません。このワークシートは、将来の対応を構想し、実現の条件を考えるためのものです。

CADについては、作図、原寸出力や型紙からのけがき、加工を区別します。CADで図を描くことから、自動的に木材表面へ線が写るわけではありません。原寸出力の倍率や基準面・基準線、木目方向、加工代、寸法の確認を計画します。CAD/CAMと工作機械による加工では、さらに工具や加工経路、材料の固定、機械の操作と管理が必要です。


## 問い1 木材加工の何を学ぶか

現行の学習指導要領解説の「材料と加工の技術」を読み、材料の特徴、加工、設計、製作、評価・改善のうち、自分の提案で中心にする学習を一つ選びます。木材の異方性、水分による変化、接合のいずれかについて、生徒が説明できるようにしたい内容を書いてください。

## 問い2 検討案と照合する

文部科学省の「情報・技術科（仮称）」の検討資料を読み、木材加工に情報技術を組み合わせると、どのような学びが可能になるかを考えます。検討資料の公表日を記録し、現行の学習指導要領と混同しないでください。

## 問い3 一つの提案を具体化する

次の例から一つ選ぶか、自分で題材を設定してください。

- 棚板の厚さ・支持間隔とたわみを表計算で予測し、実測値と比べて設計を修正する。
- 木材の寸法変化と温湿度を記録し、使用場所や隙間の設計へ反映する。温湿度測定だけから木材含水率を直接測定したとは扱わない。
- CADで継手や組立てを作図し、原寸出力・型紙等からのけがきと手加工、または設備条件に応じたCAD/CAMによる加工を計画する。木目方向・加工代・工具の幅・接合の余裕を考慮して試作と評価を行う。設備がない場合は、提供図面や加工済み試料で検討する。

## 回答欄

| 回答ID | 記入する内容 |
|---|---|
| ICT13-01 | 生徒が解決する生活・社会の問題と、達成を確かめる条件 |
| ICT13-02 | 木材の性質と加工上の制約。材料名だけでなく方向・水分・寸法・接合等を示す |
| ICT13-03 | ICTを使う段階と、その情報が設計・製作・評価のどの判断を助けるか |
| ICT13-04 | そろえる条件、変える条件、記録する値・単位・測定方法 |
| ICT13-05 | 生徒の成果物と説明を、どの観点で評価するか。予想と実測が違った場合の見直し方 |
| ICT13-06 | 参照資料の名称・公表日・URL・参照箇所、確認できた事実、自分の提案、未確認事項 |

ICT機器を使ったという事実だけで学習の達成としません。木材の性質を根拠に判断が変わったこと、比較条件と結果を説明できることを確かめます。機器や設備、加工時の固定、粉じん、保護具、時間と人数の条件も示してください。

## 自己確認

木材科学の根拠、ICTを使う目的、測定・比較の条件、評価する生徒の説明がつながっているかを確認してください。資料で確かめた事実と、自分が提案した活動を分けて書きます。
