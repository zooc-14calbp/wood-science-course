# 木材及び木質材料学：学生用教材

中学校技術科教員を目指す学生のための教材です。木材の多孔質・異方性・水との関係を、材料の性質、加工、材料選択へ結び付けます。

第1～15回の90分オンデマンド教材の初版を配備しました。各回の教材一覧から動画・音声・字幕・配布資料を開けます。動画の時間には自己確認と休憩を含みます。

## 動画の見方

第1～10回の演習・休憩中には、画面上部に「考える時間／休憩中（音声なし）」と残り時間・再開時刻を表示します。カウントダウンが進んでいる間は、動画が正常に再生されています。字幕をオフにしても、この表示は見えます。

音声はNanami（速度 -5%）。動画内の問いは自己確認用です。必要に応じて一時停止して計算や作図に取り組んでください。MP4には日本語字幕と章区切りを収録しています。字幕の表示は再生ソフトで選択してください。
