## 動画の見方

第1～9回の演習・休憩中には、画面上部に「考える時間／休憩中（音声なし）」と残り時間・再開時刻を表示します。カウントダウンが進んでいる間は、動画が正常に再生されています。字幕をオフにしても、この表示は見えます。

音声はNanami（速度 -5%）。動画内の問いは自己確認用です。必要に応じて一時停止して計算や作図に取り組んでください。MP4には日本語字幕と章区切りを収録しています。字幕の表示は再生ソフトで選択してください。
