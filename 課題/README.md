## 回答を整理する方法

- 計算：式 → 代入と単位 → 結果 → 比較・判断。
- 調べ学習：出典 → 確認できた事実 → 自分の判断 → 未確認事項。
- 図表：条件・単位・出典を示し、結論と説明を本文にも入力します。
- 提出前：回答IDの検索とPDFの表示を確認し、Teamsの提出状態を確かめます。

`.txt`の回答フォームは貼り付け等の補助用です。提出物は専用フォームで作成したPDFとします。
