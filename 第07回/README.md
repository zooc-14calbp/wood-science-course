密度と比重の定義、全乾・気乾・基本の基準状態、空隙率のモデルを扱います。自由水と壁内の水、FSP・EMC、気乾含水率約15%の位置づけ、地域・季節差を見通し、計算と観察計画へ進みます。

37画面、Nanami（速度−5%・既定ピッチ）、字幕510件。休憩は22:51、48:53、75:09から各約85秒です。説明の後に計算・作図・記述の時間と解説があります。必要に応じて一時停止してください。MP4には選択式の日本語字幕と章区切りを収録しています。

## 音声が流れない区間について

演習で考えたり、計算・作図・記述したりする時間は意図した無音区間です。画面上部に「考える時間（音声なし）」または「休憩中（音声なし）」、残り時間、再開時刻を表示します。カウントダウンが進んでいれば動画は再生中で、表示が終わると音声が再開します。この表示は字幕をオフにしても見えます。

MP3にも演習・休憩の無音区間を含みます。残り時間の表示はMP4で確認できます。
