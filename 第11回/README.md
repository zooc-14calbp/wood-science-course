# 第11回　木材の接着と塗装

- [授業スライド PPTX](11_木材の接着と塗装.pptx)
- [PDF](11_木材の接着と塗装.pdf)

- [配布資料 PDF](11_接着と塗装_配布資料.pdf) ／ [テキスト](11_接着と塗装_配布資料.md)

一般的な木工用ボンド、瞬間接着剤（アロンアルフア等）、レゾルシノール系、エポキシ系、EPI系、PF・UF等を比較します。接着の形成、工程、乾燥強さ・耐水性・耐久性、破壊位置、強度と保持率の仮想計算、塗装と保守を扱います。

説明・思考・演習を合わせた90分のシナリオに対応します。この回の動画・音声は未制作です。第11回27枚、第12回25枚、第13回20枚。出典と説明を発表者ノートへ記載しました。

演習は自己確認用。正式な[課題A4](../課題/A4_木質材料を選び授業にする_学生用.docx)は第15回後の既存設問・回答フォームを使用します。設問・配点は変更していません。
