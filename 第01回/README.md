## オンデマンド（90分・タイトル付き）

- Dropbox：このフォルダーの `01_オンデマンド_授業動画_タイトル付き.mp4` を開いてください。
- GitHub：[動画・MP3・字幕](https://github.com/zooc-14calbp/wood-science-course/releases/tag/lecture01-20261024-r3)
- [授業スライド PDF](01_オンデマンド_授業スライド.pdf) ／ [PPTX](01_オンデマンド_授業スライド.pptx)
- [配布資料 PDF](01_オンデマンド_配布資料.pdf) ／ [テキスト](01_オンデマンド_配布資料.md)
- [字幕 SRT](01_オンデマンド_授業動画.srt) ／ [VTT](01_オンデマンド_授業動画.vtt)

冒頭に講義名・科目コードなどを記載したタイトルページがあります。音声はNanami（速度 -5%）。休憩3回と考える時間を含め90分です。字幕は再生ソフトで選択してください。計算や図を見直す際は一時停止できます。

演習と復習は自己確認用です。提出課題A1～A4の提出方法・締切は授業の指示に従ってください。
