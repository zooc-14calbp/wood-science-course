音声はNanami、速度 -5%。休憩3回と、問いを考える時間を含めて90分です。動画には章区切りと日本語字幕が入っています。字幕は再生ソフトで選択してください。必要に応じて一時停止して図や式を確かめます。動画中の問いは自己確認用で、提出課題は授業で指示するA1～A4です。

三方向と三断面の図では、丸太の外周から髄へ板を平行に取る過程を読みます。板目板から追い柾、柾目板へ移ると、板幅と木材のR・T方向との対応が変わります。板取りと異方性を、寸法変化や反りの違いへつなげて考えてください。
