# 樹木・木材史の補足解説と用語の確認

第11・12回の改訂準備用補足資料。2026年10月31日。

## 用語を確かめる

専門用語を調べる際は、日本木材学会・木材教育委員会編の[木材学用語集](https://www.jwrs.org/WTerm/)を利用してください。確認した版はVer. 2.0、2025年2月1日更新です。ページ内を検索して、日本語の見出しと英語を対応させられます。以下は本講義のために短く言い換えた説明です。

| 用語 | この講義での説明 |
|---|---|
| 維管束 vascular bundle | 水や養分を運ぶ木部と師部を含む組織のまとまり。 |
| 木部 xylem | 水の通導などを担う組織。一次木部と二次木部を区別する。 |
| 師部（篩部）phloem | 光合成産物などの輸送を担う組織。講義では「師部」を基本表記とする。 |
| 維管束形成層 vascular cambium | 木部側と師部側に新しい二次組織を加える分裂組織。 |
| 二次木部 secondary xylem | 維管束形成層の活動によって生じる木部。 |
| 異方性 anisotropy | 調べる方向によって性質が異なること。木材ではL・R・T方向を対応させる。 |

木材という材料を理解するときは、細胞の壁・内腔、細胞の配列、その向きを図で確認します。用語だけを覚えるより、材料のどの場所を指しているかを確かめることが大切です。

## 第11回：植物の体を、木材から少し広げて見る

維管束を扱うと、木材だけでなく、根・茎・葉のつながりへ視野が広がります。茎が長くなる成長と、形成層が二次木部などを加える成長を分けて考えます。前者と後者は、同じ「成長」という言葉でも注目する場所が違います。木材の通導・支持に関わる組織の理解は、繊維に沿う方向と横切る方向で材の性質が違う理由を説明する土台にもなります。

参考：ポーラ・ルダル著、鈴木三男・田川裕美訳『植物解剖学入門―植物体の構造とその形成』八坂書房、1997年、28–29、37、41–42頁。[書誌情報](https://ndlsearch.ndl.go.jp/books/R100000002-I000002589550)

大きさと年齢も区別します。太い幹は、それまでの成長の積み重ねを示しますが、太さだけでは樹齢は決まりません。樹木の構造と働きは、年齢・大きさ・生育環境を分けて比較すると理解しやすくなります。「個体が存続する期間」「葉や細胞などの部分が働く期間」「伐採した材を使う期間」も、それぞれ別の時間です。

参考：Hinckleyほか（2011）A Lifespan Perspective on Integrating Structure and Function in Trees, 3–5頁。Meinzer・Lachenbruch・Dawson編 Size- and Age-Related Changes in Tree Structure and Function 所収。[章のDOI](https://doi.org/10.1007/978-94-007-1242-3_1)

## 第11回：木製井戸から加工技術と年輪を考える

Tegelほか（2012）は、ドイツ東部の新石器時代の木製井戸4基を調べ、オーク材の年輪と加工を検討しました。論文にある紀元前5469–5098年という範囲は、調べた木材の年輪系列が対応する年代です。井戸を建てた期間全体をそのまま示す数字ではありません。伐採・建設に関わる年代は、最外側の年輪や辺材の残り方も検討して推定しています。

ここでは「金属工具がなければ複雑な木工はできない」と決めつけず、接合部や加工痕を根拠に考えます。同時に、木材は保存条件に左右されるため、残った遺物の数をその時代の使用量と同一視しないようにします。年輪の読み方と、水分・生物劣化・保存の知識が、歴史を調べる技術にもつながる事例です。

原著：Tegelほか（2012）[Early Neolithic Water Wells Reveal the World's Oldest Wood Architecture](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0051374)。論文名の「最古」は発表時の表現で、ここでは現在の最古記録として覚える必要はありません。

## 第12回：建築用材は、森林からどのように届くか

木の文化には、森林と建物を結ぶ輸送や市場も含まれます。藤田叔民『近世木材流通史の研究』は丹波材を対象に、木材需要、流通、地域社会の関係を調べています。序章では、都市の需要と供給地の拡大、河川・内海を使う輸送を論点としています。

この事例を学ぶ際は、森林で必要な材を育てる段階、伐り出した材を運ぶ段階、用途に合わせて取引・加工する段階を分けます。よい材料が森林にあるだけで建築が成立するわけではありません。輸送手段、仕事を担う人、費用、必要な寸法や量を調整する仕組みまで見ると、森林管理と木造建築の関係が具体的になります。

参考：藤田叔民（1973）『近世木材流通史の研究―丹波材流通の発展過程』大原新生社、20–23頁。[書誌情報](https://ndlsearch.ndl.go.jp/books/R100000002-I000001146768)。丹波の個別事例を、日本の全時代・全地域に共通する唯一の姿として扱わないことも大切です。

## さらに話題を探すとき

授業で紹介する事実は、専門書・原著・公的資料を確認して説明します。広い概観を得るための読み物として、[Royal Forestry Societyの樹木進化のページ](https://rfs.org.uk/learning/tremendous-trees/tree-evolution/)や[植物進化史の項目](https://en.wikipedia.org/wiki/Evolutionary_history_of_plants)もあります。地質年代の境界年は資料の更新時期により違いがあるため、必要な場合は[国際層序委員会の年代表](https://stratigraphy.org/chart/)を参照します。
