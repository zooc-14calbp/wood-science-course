第1部は地球環境、維管束、木本植物の系統上の位置、木材形成と長寿です。第2部は初期人類の木材利用から、材料・燃料としての利用史、木工道具と加工方法へ進みます。

今回、55〜68ページに木工道具史を追加しました。石から鉄、打割製材と挽割製材、鋸の縦挽き・横挽き、鉋の逆目、鑿による局部加工、計測と機械化を扱います。木材の性質と道具の選択を、中学校の工作に結び付けて説明します。
