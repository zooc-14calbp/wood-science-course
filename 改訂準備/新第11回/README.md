## 学修時間と現時点の確認

動画は17分49秒です。ワークシートの資料読解・作図・計算・説明を書く活動を合わせて約90分を計画しています。活動時間は試行前の目安です。90分相当の内容として十分かは今後の確認事項です。必要に応じて動画を止めて活動し、指定時間まで待つ必要はありません。

動画全編の復号、全30ページと切替29か所、字幕時刻と音声信号を機械点検しました。人による全編聴取、上位モデルによる厳格校正、学生による活動時間の試行は未実施です。
