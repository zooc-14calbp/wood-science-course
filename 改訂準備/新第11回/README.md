第1部は地球環境、維管束、木本植物の系統上の位置、木材形成と長寿です。第2部は初期人類の木材利用から、材料・燃料としての木材利用史へ進みます。

今回、木本と分類群の違い、ヤシ・木生シダとの比較、サメ・二枚貝・ヒドラの長寿や老化、初期の火、Kalambo Fallsの木組み、Clactonの木製尖頭器を加えました。観察された事実、年代推定、用途の解釈を区別します。
