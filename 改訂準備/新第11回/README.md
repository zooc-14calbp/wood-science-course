第1部は地球環境、維管束、木本植物の系統上の位置、木材形成と長寿です。第2部は初期人類の木材利用から、材料・燃料としての利用史、木工道具と加工方法へ進みます。

実物写真・歴史図版・研究者の公開画像14点の説明に、古気候と現代のグラフ、環境の比較、木製尖頭器・槍の発見地図を加えました。木生シダの断面、長寿樹と貝殻、発掘木材、歴史的な製材と道具、鑿・台鉋・墨壺を扱います。形・材質・加工方法・用途をつなげて読みます。

## 再生時間と学修

78ページ・65分34秒から、**96ページ・93分13秒**へ増補しました。説明動画で約90分の構成になりました。短い理解確認は必要に応じて一時停止してください。ワークシート全問を必須とするものではありません。
