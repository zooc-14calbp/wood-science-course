# 毎週の受講確認

[受講確認票をダウンロード（Excel）](05242020_受講確認_YYYYMMDD_学籍番号.xlsx)

**毎週木曜日13時までに、Teamsの指定先へ提出してください。前の週から変更がなくても毎週提出します。** 対象となる週、開始・終了日、休講等の扱いはTeamsで確認してください。

1. 初回は氏名・学籍番号を記入します。以後も同じ票を累積して更新します。
2. 提出対象日には、その週の木曜日の日付を記入します。
3. 各回の状態を「未着手・途中・完了」から選び、完了した回には完了日を記入します。一部視聴は「途中」です。完了の範囲はTeamsの配信時の指示に従ってください。
4. 「今週の状況」と次の受講予定日を記入します。進捗がない場合も受講欄を残し、「今週は変更なし」を選んで提出します。連絡欄は任意です。
5. ファイル名を **05242020_受講確認_YYYYMMDD_学籍番号.xlsx** にし、Teamsから提出します。YYYYMMDDは提出対象の木曜日の日付です。例：05242020_受講確認_20261105_12345678.xlsx（例示であり、初回期限の指定ではありません）。

受講確認票はExcelで提出します。A1～A4のレポートは専用フォームから作るPDFで、従来どおり「05242020_課題コード_学籍番号.pdf」です。

受講確認は進み具合の自己申告です。理解・学習成果はA1～A4等も用いて確認し、受講確認と成績評価は分けて扱います。個人情報を含む提出票を公開GitHubに置かないでください。
