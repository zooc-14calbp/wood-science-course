# 第12回　合板・LVLとボード類

- [授業スライド PPTX](12_合板_LVLとボード類.pptx)
- [PDF](12_合板_LVLとボード類.pdf)

従来の合板・LVLとボード類を統合。単板・小片・繊維・ストランド、配向、製法、密度、接着と使用条件を比較します。積層方向と密度の計算、家具側板の材料選択を含みます。

説明・思考・演習を合わせた90分のシナリオに対応します。この回の動画・音声は未制作です。第11回27枚、第12回25枚、第13回20枚。出典と説明を発表者ノートへ記載しました。
