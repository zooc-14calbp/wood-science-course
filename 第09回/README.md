## 音声が流れない区間について

演習で考えたり、計算・作図・記述したりする時間は意図した無音区間です。画面上部に「考える時間（音声なし）」または「休憩中（音声なし）」、残り時間、再開時刻を表示します。カウントダウンが進んでいれば動画は再生中で、表示が終わると音声が再開します。この表示は字幕をオフにしても見えます。

MP3にも演習・休憩の無音区間を含みます。残り時間の表示はMP4で確認できます。
